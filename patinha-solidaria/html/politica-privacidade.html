A Patinha Solidária respeita a sua privacidade. Neste projeto acadêmico:

  • Os dados dos formulários ficam salvos apenas no seu navegador, usando o localStorage.
  • O CPF é usado somente para validação e não é armazenado no rascunho automático.
  • Nenhuma informação é enviada para servidores externos, exceto o CEP, consultado na API pública ViaCEP para preencher o endereço.
  • Você pode apagar seus dados a qualquer momento limpando o armazenamento do navegador ou usando os botões "Limpar" do site.
